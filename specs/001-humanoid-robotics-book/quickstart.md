# Quickstart Guide: Book on Physical AI & Humanoid Robotics

This guide provides quick steps to set up the development environment and get started with contributing to or building the "Book on Physical AI & Humanoid Robotics".

## For Readers: Setting up the Simulation Environment

Detailed instructions on setting up various simulation environments (ROS 2, Gazebo, NVIDIA Isaac Sim, Unity) will be provided within the book's chapters.

## For Contributors: Setting up the Docusaurus Project

1.  **Clone the Repository**:
    ```bash
    git clone [repository_url]
    cd [repository_name]/book-src
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Start Local Development Server**:
    ```bash
    npm run start
    ```
    This command starts a local development server and opens a browser window. Most changes are reflected live without restarting the server.

## Code Examples

All reproducible code examples are located in the `code-examples/` directory. Refer to the `README.md` within each example's subdirectory for specific setup and execution instructions.
